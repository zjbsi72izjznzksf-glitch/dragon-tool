# 🐉 Dragon Station [Master Cyber Defense & Operations Suite]

**Dragon Station** is an all-in-one local cybersecurity auditing, offensive reconnaissance, and defensive operations platform built with Python and Flask. Designed specifically to run seamlessly in mobile environments like Termux, it integrates 12 essential cybersecurity modules into a unified, high-performance web dashboard.

---

## 🚀 Key Features & Modules

1. **Password Entropy Auditor**: Evaluates password strength using cryptographic entropy calculations.
2. **Security Headers Audit**: Checks target web applications for essential security headers (`HSTS`, `CSP`, `X-Frame-Options`, etc.).
3. **SSL/TLS Certificate Auditor**: Validates certificate trust chains, issuers, and expiration dates.
4. **HTTP Methods Recon**: Identifies allowed HTTP request methods on remote servers.
5. **Robots.txt Analyzer**: Extracts and previews web routing exclusion rules.
6. **DNS & IP Lookup**: Resolves domain names to IP infrastructure.
7. **URL & Parameter AppSec Analyzer**: Deconstructs target URLs and query parameters for security review.
8. **Port Reachability Recon**: Performs quick TCP socket reachability scans across standard network ports.
9. **Cryptographic Hash & Codec**: Computes `MD5`, `SHA256`, and `Base64` transformations locally.
10. **Vulnerability & CVE Watcher**: Matches software services against a built-in evaluation registry.
11. **Network Diagnostic**: Inspects local interface connectivity and IP configurations.
12. **SIEM Log Core**: Centralized auditing trail and event monitoring engine.
